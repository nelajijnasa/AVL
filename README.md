# 🌳 AVL Tree Visualization - Web UI Project

This is an interactive web application designed to **visualize AVL Tree operations**. It helps users understand how **self-balancing Binary Search Trees (BSTs)** work, how AVL trees maintain balance, and how different rotations are applied during insertions and deletions.

---

## 📌 Project Objective

To provide an **educational, visual platform** that:
- Demonstrates **insertions** into an AVL tree.
- Shows **automatic balancing** using LL, RR, LR, RL rotations.
- Helps learners visualize AVL tree structure dynamically.

---

## 🚀 Features

- ✅ Real-time insertion of nodes
- 🔁 AVL tree automatically balances itself
- 📊 Supports all 4 types of rotations:
  - LL (Left-Left)
  - RR (Right-Right)
  - LR (Left-Right)
  - RL (Right-Left)
- 🌱 Color-coded nodes for better visualization
- 📱 Responsive UI
